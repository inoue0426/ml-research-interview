## Drills
1. 7B と 70B がほぼ同じ validation performance。
2. Training loss は改善するが downstream performance は悪化。
3. More data を入れたら性能が下がった。
4. New architecture は in-domain だけ改善。
5. Agent benchmark は改善したが human evaluation は変わらない。
6. Model A は average で勝つが variance が大きい。
7. Scientific model が random split では強いが scaffold/cell-line split で崩れる。
8. Ablation で全 component が重要に見える。
9. Scaling curve が途中から flatten した。
10. Reward が上がるほど actual task quality が下がる。
