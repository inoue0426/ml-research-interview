# ML / Research English Cheatsheet

日本語で理解した内容を、面接や研究議論で自然な英語に変換するための表現集。

## Experiment / Research Design

| 日本語 | English |
|---|---|
| 仮説を検証する | test the hypothesis |
| 影響を調べる | investigate the effect of |
| 効果を切り分ける | isolate the effect of |
| 条件を統制する | control for |
| 比較する | compare against / compare with |
| アブレーションを行う | conduct an ablation study |
| 再現性を確認する | assess reproducibility |
| 頑健性を評価する | evaluate robustness |
| 交絡要因 | confounding factor |
| 仮定を置く | make an assumption |

## Results

| 日本語 | English |
|---|---|
| 性能が向上した | performance improved |
| 一貫した改善 | consistent improvement |
| 改善は限定的だった | the improvement was marginal |
| 統計的に有意 | statistically significant |
| 差はほとんどない | there is little difference |
| 結果が不安定 | the results are unstable |
| ベースラインを上回る | outperform the baseline |
| 性能が飽和する | performance saturates |

## Model Behavior

| 日本語 | English |
|---|---|
| 過学習する | overfit |
| 収束する | converge |
| 発散する | diverge |
| 飽和する | saturate |
| 不安定になる | become unstable |
| 情報を伝播する | propagate information |
| 長距離依存を捉える | capture long-range dependencies |
| 表現を学習する | learn representations |
| ボトルネックになる | become a bottleneck |
| スケールする | scale |

## Reasoning / Explanation

| 日本語 | English |
|---|---|
| 直感的には | intuitively |
| より正確には | more precisely |
| 主な理由は | the main reason is |
| 重要な違いは | the key distinction is |
| これは〜を意味する | this implies that |
| 〜と考えられる | one possible explanation is |
| この仮説と整合的 | consistent with this hypothesis |
| 必ずしも〜を意味しない | does not necessarily imply |
| トレードオフ | trade-off |
| 制約する | constrain |

## Useful Interview Phrases

- "I would start by making the assumptions explicit."
- "The key trade-off here is ..."
- "One possible failure mode is ..."
- "I would test this with an ablation that ..."
- "The result is consistent with the hypothesis, but it does not by itself establish causality."
- "A simpler baseline would help determine whether the added complexity is actually necessary."
- "From a systems perspective, the main bottleneck is ..."
- "If we relax this assumption, I would expect ..."
