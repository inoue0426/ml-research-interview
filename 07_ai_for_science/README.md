## Questions to Think About

- What makes biological foundation models different from language models?
- When does biological inductive bias help?
- When should we prefer a general-purpose foundation model?
- What does generalization mean in a biological setting?
- How should experimental feedback enter model training?
- How do we distinguish predictive performance from scientific usefulness?
- How should we evaluate models when ground truth is noisy or incomplete?
- How can agents interact with scientific tools and experimental pipelines?
