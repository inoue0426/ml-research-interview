# Papers

大量の論文要約を作るのではなく、面接や研究議論で説明すべき canonical / important papers を厳選する。

## Suggested Groups
- Foundation models / Transformers
- LLM training
- RL / post-training
- Interpretability
- AI for Science
- Must-explain papers related to my research

## Paper Note Format
1. One-sentence contribution
2. Problem
3. Core idea
4. Key equation / algorithm
5. Experimental evidence
6. Why it worked
7. Weaknesses / assumptions
8. What came after it
9. What would I ask the authors?
