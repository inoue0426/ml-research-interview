# Reinforcement Learning

LLM post-training につなげることを意識して学ぶ。

## Learning Path

```text
MDP
 ↓
Bellman equation
 ↓
Value / Q function
 ↓
Monte Carlo / TD
 ↓
Q-learning
 ↓
Policy gradient
 ↓
Actor-Critic
 ↓
Advantage / GAE
 ↓
TRPO
 ↓
PPO
 ↓
Reward modeling / RLHF / LLM RL
```
