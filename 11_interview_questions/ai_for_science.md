# Interview Questions — AI for Science

- [ ] What makes scientific ML different from standard benchmark ML?
- [ ] What is a meaningful OOD split in biology?
- [ ] Why can random splits be misleading?
- [ ] How do you handle batch effects / technical confounding?
- [ ] Graph vs sequence vs 3D representation: when and why?
- [ ] How do you validate a model-derived biological hypothesis?
- [ ] Predictive explanation vs mechanistic explanation?
- [ ] Can scaling laws from language transfer to biology?
- [ ] How should experimental feedback enter model training?
- [ ] How would you evaluate a scientific agent?
- [ ] How should a model handle conflicting scientific evidence?
- [ ] What would prospective validation add?

For each: 日本語 → English 30 sec → English 2 min → concrete biomedical example → follow-ups.
