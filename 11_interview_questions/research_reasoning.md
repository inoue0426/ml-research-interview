# Interview Questions — Research Reasoning

- [ ] 7B→70B で性能が上がらない。何を調べる？
- [ ] Training loss は改善するが downstream performance が悪化。なぜ？
- [ ] More data made performance worse. Hypotheses?
- [ ] A method works only in-domain. Next experiments?
- [ ] How do you design a convincing ablation?
- [ ] How do you choose the cheapest discriminating experiment?
- [ ] Tell me about a failed hypothesis.
- [ ] How do you know an observed gain is not from extra compute?
- [ ] How do you distinguish correlation from mechanism?
- [ ] When should you stop a research direction?

Answer structure:
1. clarify observation / assumptions
2. hypotheses grouped by data / optimization / model / objective / evaluation
3. prioritized discriminating experiments
4. expected outcomes
5. confounders
6. next decision

English practice: 2–5 min per problem.
