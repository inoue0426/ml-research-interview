# Minimum Master Checklist

面接準備の最終確認。詳細は各カテゴリの `minimum_knowledge.md` を参照。

## Tier 1 — 必須
- [ ] Backpropagation を説明・簡単に導出できる
- [ ] Cross entropy / KL / MLE の関係を説明できる
- [ ] Bias–variance / regularization / data leakage を説明できる
- [ ] Self-attention を数式から説明できる
- [ ] `sqrt(d_k)` scaling を説明できる
- [ ] Multi-head attention を実装できる
- [ ] Transformer block を白板で再構成できる
- [ ] Pretraining → SFT → preference optimization を説明できる
- [ ] KV cache と inference bottleneck を説明できる
- [ ] Policy gradient → actor-critic → PPO の流れを説明できる
- [ ] 70B model の training memory を概算できる
- [ ] DP / FSDP / TP / PP の違いを説明できる
- [ ] Open-ended research problem を hypothesis と experiment に分解できる
- [ ] 自分の主要研究を 30 sec / 2 min / 10 min で説明できる
- [ ] 自分の研究の weak point を defend できる
- [ ] medium difficulty の coding problem を complexity 付きで解ける

## Tier 2 — Frontier-model depth
- [ ] scaling laws / compute-optimal training
- [ ] data mixture / contamination / deduplication
- [ ] PPO vs DPO
- [ ] reward hacking / specification gaming
- [ ] MQA / GQA
- [ ] RoPE / positional encoding
- [ ] long-context limitations
- [ ] quantization / speculative decoding
- [ ] evaluation contamination / pass@k / model-based eval
- [ ] mechanistic interpretability の基本目的

## Tier 3 — Differentiator
- [ ] Scientific ML における OOD split を説明できる
- [ ] biological representation choice を defend できる
- [ ] GNN vs Transformer を研究課題に応じて議論できる
- [ ] scientific validity と predictive accuracy の違いを説明できる
- [ ] AI-generated hypothesis の evaluation design を議論できる
- [ ] 自分の biomedical ML experience を frontier AI research へ自然につなげられる

## Readiness Test
各 Tier 1 項目について次の4つがすべて Yes なら ready。

- [ ] 日本語で直感的に説明できる
- [ ] 数式 / implementation detail に降りられる
- [ ] 英語で30秒回答できる
- [ ] follow-up を2〜3問受けても破綻しない
