# Interview Questions

各分野で学んだ内容を、最終的に interview-ready な Q&A に収束させる場所。

## Categories
- ML
- Deep learning
- Transformers
- LLMs
- Reinforcement learning
- ML systems
- Research reasoning
- AI for Science
- My research
- Coding

## Question Format

```markdown
# Question

## 日本語で考える

## Short Answer (English, ~30 sec)

## Deep Answer (English, ~2 min)

## Mathematical / Technical Detail

## Common Pitfalls

## Follow-up Questions
```

重要なのは「知っているか」ではなく、短時間で構造化して説明し、follow-up に耐えられるかを確認すること。
